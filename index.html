02 · Senses

Motion: the phone knows how you move it

// iOS needs a tap first, then the same events as Android
await DeviceMotionEvent.requestPermission?.();

addEventListener('devicemotion', e => {
  const { alpha, beta, gamma } = e.rotationRate;   // degrees per second
  const speed = Math.hypot(alpha, beta, gamma);
  if (speed > 350) castSpell();                   // a wand flick
});

02 · Senses

Compass: which way is Marina Beach?

// Android: true north on a separate event
addEventListener('deviceorientationabsolute', e => heading = 360 - e.alpha);

// iOS: a non-standard field on the normal event
addEventListener('deviceorientation', e => heading = e.webkitCompassHeading);

arrow.style.rotate = `${bearingTo(MARINA) - heading}deg`;

02 · Senses

The microphone is a sensor, not just a recorder

const mic = await navigator.mediaDevices.getUserMedia({ audio: true });
const analyser = audioCtx.createAnalyser();
audioCtx.createMediaStreamSource(mic).connect(analyser);

analyser.getByteTimeDomainData(buf);
const loudness = rms(buf);            // blowing on the mic = very loud
balloon.scale += loudness * 0.12;

03 · Hardware

The flashlight is a camera setting

const stream = await navigator.mediaDevices.getUserMedia({
  video: { facingMode: 'environment' },
});
const [track] = stream.getVideoTracks();

if (track.getCapabilities().torch) {
  await track.applyConstraints({ advanced: [{ torch: true }] });
}

That’s how the light show worked. iPhone falls back to flashing the screen.

05 · Android vs iPhone, honestly

Android Chrome gets most of it

Android ChromeiPhone Safari
Motion, compass, mic, share, wake lock, speechYesYes
Flashlight, vibrationYesWorkarounds

07 · Takeaways

Before you reach for a native app…

  1. Check the web first. Sensors, NFC, Bluetooth and OTP are a few lines of JS.
  2. Build for Android, degrade for iPhone. Feature-detect every API.
  3. Make it physical. Shaking, tilting and tapping stickers is what people remember.
